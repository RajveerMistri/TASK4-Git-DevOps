\# Git Workflow



\## Main Branch



The `main` branch contains the stable version of the project.



\## Development Branch



The `dev` branch is used for integrating completed features before release.



\## Feature Branches



Features are developed independently using branches such as:



```text

feature/add-documentation

feature/update-app

## Development Best Practices

The following Git best practices are followed in this project:

1. Use separate branches for development.
2. Use feature branches for individual changes.
3. Create Pull Requests before merging.
4. Keep commits meaningful and descriptive.
5. Use `main` for stable releases.
6. Use tags to identify project versions.
